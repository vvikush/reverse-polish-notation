# Function Graph Plotter

Консольная программа на языке C для построения графиков математических функций в терминале.

Программа принимает выражение `f(x)` в виде строки, разбирает его на лексемы, переводит выражение из инфиксной записи в обратную польскую нотацию с помощью алгоритма Дейкстры, вычисляет значения функции и выводит график в виде ASCII-сетки.

## Возможности

- ввод математического выражения в виде строки;
- лексический разбор выражения;
- проверка корректности выражения;
- перевод выражения в Reverse Polish Notation;
- вычисление выражения через стек;
- построение графика в терминале;
- обработка некорректного ввода;
- модульная структура проекта.

## Поддерживаемые операции и функции

Поддерживаются:

- сложение: `+`;
- вычитание: `-`;
- умножение: `*`;
- деление: `/`;
- возведение в степень: `^`;
- скобки: `(` и `)`;
- переменная `x`;
- функции `sin`, `cos`, `tan`, `sqrt`, `ln`, `exp`, `fabs`.

## Формат графика

График строится на поле размером `80 x 25`.

Параметры области построения:

- область определения: `[0; 4π]`;
- область значений: `[-1; 1]`;
- символ графика: `*`;
- символ пустого пространства: `.`;
- оси координат не отображаются.
